# Task 23 — SQL Aggregation Basics

**Track:** Data Analytics  
**Topic:** `COUNT`, `SUM`, `AVG`, `MIN`, and `MAX`  
**Tool selected:** MySQL  
**Suggested dataset:** Northwind

## Objective
Practice SQL aggregate functions, grouping records, filtering groups with `HAVING`, and checking how aggregate functions handle `NULL` values.

## Files
- `sql/task23_aggregation_queries.sql` — 10 aggregation queries
- `results/expected_results.md` — purpose and expected shape of each result
- `results/submission_checklist.md` — verification and submission checklist

## Setup
1. Install/open MySQL and import the Northwind sample database.
2. Open the SQL file in MySQL Workbench.
3. Confirm table and column names in your Northwind version.
4. Run queries one at a time and inspect the result grid.
5. Capture screenshots of queries and results if required by the internship portal.

## Tool choice
The screenshot lists MySQL and PostgreSQL. This project uses **MySQL only**.

## Dataset note
Queries target the common Northwind tables: `customers`, `orders`, `order_details`, `products`, and `categories`. Names can differ between Northwind versions, so adjust identifiers if needed.

**Accuracy note:** The SQL and result guide are prepared for practice. Run the queries on your imported database to obtain actual result values; no database execution was performed while creating this pack.
